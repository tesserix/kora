Primary action control — use for any tappable action; `default` is the filled brand button, `outline`/`ghost` for secondary, `link` for inline.

```jsx
<Button>Log meal</Button>
<Button variant="outline" size="sm">Edit</Button>
<Button variant="success" isLoading loadingText="Saving…">Save</Button>
```

Variants: default, destructive, outline, secondary, ghost, link, success, warning.
Sizes: default (h40), sm (h36), lg (h48), xl (h56), icon / icon-sm / icon-lg (square).
