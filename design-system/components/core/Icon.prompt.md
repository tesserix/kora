Renders a Lucide icon by name — Tesserix's icon system. Requires the lucide UMD script on the page.

```jsx
<Icon name="camera" size="lg" />
<Icon name="flame" color="var(--primary)" />
<Icon name="chevron-right" size={16} />
```

Names are Lucide names (kebab or Pascal). Sizes: xs 12, sm 16, md 20, lg 24, xl 32, 2xl 40, or a number.
