Surface container for grouped content. Default is bordered with a soft large shadow; `glass` is translucent with backdrop blur (great over imagery).

```jsx
<Card>
  <CardHeader>
    <CardTitle>Breakfast</CardTitle>
    <CardDescription>412 kcal · 3 items</CardDescription>
  </CardHeader>
  <CardContent>…</CardContent>
</Card>
```

Slots: CardHeader, CardTitle, CardDescription, CardContent, CardFooter.
