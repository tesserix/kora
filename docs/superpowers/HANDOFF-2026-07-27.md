## Gotchas
- **GORM zero-time:** a bare `time.Time` on a `DEFAULT now()` column inserts Go zero time and overrides it — tag `autoCreateTime`/`autoUpdateTime`.
- **`git add -A` slip:** the repo dir carries an untracked `.idea/` (now gitignored). Never `git add -A` blindly — stage explicit paths.
- Config has **no `.env` auto-load** — the backend needs env exported.
- Push copy is server-generated and mirrors the in-app `message()` strings verbatim; the outbox covers both E1 action-rows and E2a scheduler-rows because both go through `notifications.Repository.Create`.
