# Sketch Manifest

## Design Direction
Kora's "Instrument Glass" language stays: dark-first, warm-lume ink `#EDE6D4` on
`#0B0D10`, orange accent `#FF4A00` (dark) / `#D23800` (light), Menlo tabular numerals,
engraved uppercase micro-labels, and the 230° SVG meter gauge — all untouched. The
problem being explored is panel monotony: every section is currently the same
blur-glass card at the same weight. Sketches explore structures (fusion, removal,
size variation) that give screens hierarchy without adding colors or breaking the
one-accent-per-view rule from the 2026-08-11 instrument-glass spec.

## Reference Points
The app's own spec: `docs/superpowers/specs/2026-08-11-kora-instrument-glass-design.md`.
Direction cues: automotive/aviation instrument clusters, editorial data pages, bento dashboards.
