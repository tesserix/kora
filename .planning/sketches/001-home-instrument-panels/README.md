# Sketch 001: Home Instrument Panels

## Design Question
The current Home screen stacks six near-identical GlassPanels (hero gauge, protein
strip, carbs/fat pair, vitals strip, saved strips, logged list). Everything reads at
the same visual weight — "ordinary". What panel structure gives the screen hierarchy
and character while keeping the meter gauge and the orange accent (`#FF4A00` /
`#D23800`) exactly as they are?

## How to View
open .planning/sketches/001-home-instrument-panels/index.html

## Variants
- **A: Instrument cluster** — gauge, macro rail, and vitals fuse into one sculpted bezel panel with engraved zone rules and a recessed vitals well; the logged list floats card-free below.
- **B: Editorial hairline** — *rejected by user (round 1)*. No cards on data at all; kept for reference.
- **C: Bento depth** — keeps glass but breaks monotony with size: asymmetric bento (tall protein tile, stacked carbs/fat, mini vitals), radial top sheens, and a faint orange rim glow on the hero only.
- **D: Ignition** — round-2 synthesis and Claude's pick: A's cluster + C's layered light + B's card-free meal list, with an ignition needle sweep and reserve count-down on entry, warm lume glow, brushed conic bezel, one-time specular sweep, and a redesigned dock (slimmer capsule, icons-only with engraved active label, capture button carved into a notch instead of floating).

## What to Look For
- Which structure makes the gauge feel most like the hero?
- Accent discipline: the spec allows roughly one orange element per view — does each variant stay honest?
- Toggle light mode in the bottom-right toolbar; press "Log a meal" to watch the needle, sub-dials, and list update together.
- A tests fusion, B tests removal, C tests variation — three opposite answers to the same question.
